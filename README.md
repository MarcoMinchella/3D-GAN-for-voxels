This repository contains an implementation of a Generative Adversarial Network (GAN) for generating 3D voxelized objects using the ModelNet10 dataset. 
The project demonstrates how GANs can be applied beyond 2D image generation to produce structured 3D data representations.

🚀 Features

3D voxel-based GAN architecture.
Trained and evaluated on the ModelNet10 dataset.
Support for generating novel 3D object samples across 10 categories.
Tools for data preprocessing, training, and visualization.
Modular code structure.

📂 Dataset

ModelNet10 is a subset of the ModelNet dataset containing 10 object classes (e.g., chair, table, bed, sofa).
Objects are represented as 3D voxel grids transformed from CAD files.
Dataset preprocessing scripts are provided in the data preparation directory.

📊 Results

The GAN successfully generates voxelized 3D shapes resembling categories from ModelNet10.
Example outputs are available in the PPT images and gifs directory.
